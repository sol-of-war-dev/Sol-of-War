# Contributing to Sol of War

Use the local setup in README.md and keep payment changes in simulation during development.
Work on a focused branch and describe the behavior changed, relevant tests and limitations.
Run `npm run verify:sow` before proposing a change. Preserve upstream attribution and licenses.

Do not commit credentials, private ledgers, wallet material, session exports or backups.
Do not run upstream deployment/release automation for this fork. Production releases require
the existing active-game check and deployment-drain procedure.

Issue and pull-request policies will be set when the owner creates the GitHub repository.
